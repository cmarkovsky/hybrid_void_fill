# Manuscript sources

`main/main.tex` is the main manuscript source; its `tables/`, `figures_tex/`, and `references.tex` are the required inputs. `supplement/supplement.tex` contains the eight supplementary figure captions. Figure paths refer to the repository's final `figures/main/` and `figures/supplement/` files. The six numerical result-table inputs agree with `results/manuscript/tables/`.

The source title is *A hybrid hypsometric–machine learning approach for reconstructing glacier surface elevation change*. The evaluated test population contains 1,754 glaciers, excluding RGI60-14.17287. Inactive draft paragraphs, author-source backups, edit/reconciliation histories, and draft proofs have been removed.

Build main and supplement with the Copernicus LaTeX class available, alternating builds until cross-references resolve. The class files are not redistributed. Manuscript build products are ignored by Git.

# Final manuscript results

Every summary uses the default evaluation of 1,754 test glaciers, excluding RGI60-14.17287. `evidence/` contains the source summaries for Tables 5–10 and supplementary figures. `tables/` contains six LaTeX tables, a readable Markdown version, and their unrounded values. `per_glacier_metrics.csv` supplies the method-level glacier errors. `bootstrap_intervals.csv` and `paired_bootstrap_intervals.csv` retain marginal and paired spatial-block results, including relative improvements.

The complete keyed cache, residual arrays, coverage diagnostics, and intermediate stage outputs are generated by `reproduce.py` and are not duplicated here. Bulk inputs and historical full-population records remain in the separate data archive.
